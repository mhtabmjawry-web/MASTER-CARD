# RASA — رِسا نسخهٔ PWA قابل نصب رِسا. برنامه با IndexedDB داده‌ها را در مرورگر ذخیره می‌کند و با Service Worker پوستهٔ برنامه را برای استفادهٔ آفلاین cache می‌کند. برای انتشار: در Settings → Pages، گزینهٔ Source را روی GitHub Actions بگذارید. سپس workflow این مخزن، سایت را deploy می‌کند. داده‌های فلش‌کارت به حساب GitHub منتقل یا بین دستگاه‌ها همگام‌سازی نمی‌شوند؛ در همان مرورگر و origin ذخیره می‌شوند.
